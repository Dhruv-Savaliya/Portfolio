# Dhruv Savaliya — Portfolio

> Full-Stack, Generative AI, and Interactive 3D Web Architect

A production-grade, cinematic portfolio designed with modern glassmorphism, procedural Three.js WebGL shaders, a responsive 3D Digital Core, fluid Lenis smooth-scrolling, and a dynamic dark/light theme system.

## 🚀 Highlights & Features

- **3D Digital Core**: Dynamic procedural WebGL core powered by Three.js with Fresnel rim illumination, geodesic icosahedron wireframe shell, and gyroscopic orbital rings that respond to mouse tilt and scroll section morphing.
- **Cinematic Glassmorphism**: High-contrast, mathematical design system featuring porcelain & electric blue light mode and deep obsidian neon dark mode.
- **Featured Projects**: Interactive live demos and architectural breakdowns for **BizDhan**, **ClearClaim**, and **SmartReceipt**.
- **Interactive Audio & Feedback**: Micro-synthesizer audio engine for tactile UI soundscapes with toggle controls.
- **Fluid Motion**: Lenis smooth scroll and Framer Motion transitions with respect for `prefers-reduced-motion`.
- **Production Performance**: Built with Vite, React 19, TypeScript, and Tailwind CSS. Fully compatible with Vercel deployment.

## 🛠️ Tech Stack

- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS
- **3D & Graphics**: Three.js, Custom GLSL Shaders
- **Animation**: Motion, Lenis Smooth Scroll
- **Icons**: Lucide React

## 📦 Getting Started

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
