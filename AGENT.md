# 25. Why These Libraries

## Next.js

Use Next.js as the main application foundation.

## Three.js

Use Three.js for the WebGL/3D layer.

## React Three Fiber

Use React Three Fiber for React-based Three.js components.

R3F is a React renderer for Three.js and is suitable for reusable WebGL
components.

## Drei

Use `@react-three/drei` for:

-   Helpers
-   Loaders
-   Cameras
-   Controls
-   HTML overlays
-   Common R3F utilities

## GLTFJSX

Use GLTF/GLB assets when useful and convert models into React components
where appropriate.

## GSAP + ScrollTrigger

Use GSAP as the primary cinematic animation engine.

Use ScrollTrigger for:

-   Scroll-linked animation
-   Pinning
-   Scrubbing
-   Snapping where appropriate
-   Long cinematic sequences

## Lenis

Use Lenis for smooth scrolling and synchronization with GSAP
ScrollTrigger.

Architecture:

``` text
USER SCROLL
     ↓
LENIS
     ↓
GSAP
     ↓
SCROLLTRIGGER
     ↓
DOM + 3D
```

## Zustand

Use Zustand for global experience state.

Suggested state:

``` text
soundOn
loadingProgress
currentProject
scrollProgress
activeSection
isMenuOpen
isMobile
webglReady
```

## Motion

Use Motion primarily for:

-   Small UI interactions
-   Menu
-   Modal
-   Simple reveals
-   Hover states
-   Layout transitions

Do not use Motion and GSAP to control the same animation property unless
intentionally coordinated.

## Postprocessing

Use `@react-three/postprocessing` only where necessary.

Possible subtle effects:

``` text
Bloom
Depth of Field
Vignette
Chromatic Aberration
Noise
```

Use effects lightly.

## Theatre.js

Theatre.js is optional.

Do not add it to V1 unless advanced visual timeline authoring is
actually required.
